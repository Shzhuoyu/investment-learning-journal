# 宁波银行：唯一上榜摩根士丹利最佳商业模式的银行，中报深度解读

## 前言

宁波银行（002142），唯一上榜摩根士丹利"中国最佳商业模式"的银行。这个商业模式到底好在哪？

先说清楚三件事。

**第一，这期内容是重做的。** 我之前做过一期宁波银行，当时用的是2025年年报加2026年一季报的数据。结果8月19号，宁波银行发了2026年半年报，很多关键数字都变了。做分析最怕什么？最怕数字是旧的。所以我干脆全部推翻，用最新的中报数据重做一遍。

**第二，中报刚出，市场已经先动了。** 发布后第一个交易日，宁波银行涨了3.64%，收34.18元，总市值2257亿，市盈率7.25倍。也就是说，我下面讲的估值，是在市场已经涨过之后的价位上。这一点先立在这，最后算账的时候会用到。

**第三，这篇是上篇，主角是宁波银行；下篇是兴业银行。** 兴业的中报还没发（预计8月28日披露），所以下篇用的是2025年年报加2026年一季度的数据——数据旧一点，但分析要趁早。两家放一起，就是一份"用同一把尺子，量两种银行"的对比：宁波是城商行的天花板，兴业是股份行里最便宜的那个。

那这期中报到底说了什么？一句话概括：上半年营收414.50亿，同比增长11.54%；归母净利润165.62亿，同比增长12.12%。在银行业息差还在往下走的背景下，交出了营收净利双位数的增长。

但这次我想讲的不只是"中报好不好"，而是更硬的问题：**这12%的利润增长，到底是从哪来的？** 是商业模式真的变好了，还是扩表撑起来的、会计确认的、外加非息收入爆发凑出来的？这个问题比"营收净利双增"值钱得多——因为它直接决定34.18元该给多少倍PB。

## 第一部分：认识这家银行

宁波银行1997年成立，2007年在深圳上市，代码002142，是中国最早上市的城商行之一。总部在宁波，主要经营区域就两个字：长三角。

截至2026年6月末，总资产3.9482万亿，接近4万亿；贷款1.9499万亿，存款2.2948万亿。上半年归母净利润165.62亿，加权平均净资产收益率14.24%。

在A股42家上市银行里，论规模它排不进第一梯队——国有大行和招商银行都比它大得多。但论赚钱的效率，它常年站在城商行金字塔尖。2007年上市到现在，它有一项记录在A股银行里极其罕见：**连续19年不良贷款率低于1%**。今年6月末不良率0.76%，拨备覆盖率373.35%。

一句话：这是一家把"稳"字写在脸上的银行。

但"稳"只是结果。这篇我想回答两个问题：**"稳"是怎么来的，以及——这个"稳"能不能维持下去。** 第二个问题才是买它之前真正要回答的，因为后面你会看到，有些裂缝正在它的资产负债表里慢慢扩大。

## 第二部分：中报速览——六个关键数字

在展开商业模式之前，先把中报最重要的数字过一遍，总共就六个：

**第一，营收414.50亿，同比增长11.54%。**

**第二，归母净利润165.62亿，同比增长12.12%。**

**第三，看单季：** 二季度营收210.66亿，同比增长12.86%；二季度净利润83.81亿，同比增长13.95%。注意，二季度的增速比一季度还要快——一季度净利增速大约10.3%，二季度拉到了13.95%，是逐季加速的。

**第四，收入结构：** 手续费及佣金净收入43.17亿，同比增长53.90%，占营收比重升到10.41%。这个数字很漂亮，但它到底意味着什么，我不能急着下结论——它可能说明财富管理进入了收获期，也可能只是资本市场的β。这一点我在第四部分专门拆。

**第五，资产质量：** 不良率0.76%，跟年初持平；拨备覆盖率373.35%，比年初还多了0.19个百分点。但我会在第五部分告诉你，全行0.76%这个数字下面，藏着一个正在上升的裂缝。

**第六，盈利能力：** 加权平均净资产收益率14.24%，比去年同期高了0.44个百分点。在净息差继续下行的年份里，ROE不降反升——这是整份中报含金量最高的一个数字。但同样，半年回升不等于拐点，ROE是全文最重要的跟踪对象。

## 第三部分：商业模式拆解——三条支线

2026年4月，摩根士丹利发了一份报告叫《中国最佳商业模式V2》，入选的公司有腾讯、宁德时代这些大家耳熟能详的巨头。而42家A股上市银行里，只有一家上榜：宁波银行。

摩根士丹利凭的不是谁规模大，凭的是商业模式的持续性。它的评估维度是四个：行业前景、量化指标、核心主题、基本面。给宁波银行的评价里反复出现一个词：**风控护城河**。

具体来说，它认可了这么几件事：不良率连续多年低于1%，拨备覆盖率接近374%，长期保持高ROE，负债端靠低成本结算存款，资产端投向中小微企业，规避了房地产的集中风险，还有多元化利润中心和深耕长三角。

这里面的关键词，可以归成三条主线：

1. **它做生意的地方，是中国经济最肥的一块土壤。**
2. **它赚钱不靠一条腿，而是十几个利润中心一起赚。**
3. **它的负债便宜，资产干净，利差结构在银行业里是稀缺的。**

这三条不是并列的三件事，而是一条链上的三个环节：**区域是根，结构是干，利差是果。** 根扎得深，树干才能粗；树干粗，果实才结得大。

### 支线一：经营区域——最根本的一条

银行这门生意，本质上是借地区的钱、放地区的贷、赚地区的利差。地区经济好不好，直接决定了银行的资产质量天花板。再好的风控，架不住整个区域经济塌方。而经济越活跃的地方，企业越能赚钱，贷款越不容易坏。

宁波银行的贷款，85.84%投在浙江和江苏。6月末的贷款结构：浙江省占62.60%，江苏省占23.24%，广东4.60%，上海4.22%，北京3.88%，其他省市加起来只有1.46%。浙江加江苏两个省，吃掉了它超过八成的贷款。

这听起来像鸡蛋放在一个篮子里。但问题是，这个篮子确实结实：2026年上半年，长三角三省一市GDP合计约17.36万亿元，占全国总量接近1/4。浙江上半年GDP实际增速5.7%，领跑长三角，明显跑赢全国；江苏增速5.2%，是中国经济总量第二、制造业第一的大省。

再看大本营宁波：2025年GDP 1.8716万亿，人均GDP约19.08万元、折合约2.67万美元，在全国主要城市里排第一梯队。2026年上半年宁波GDP实际增速5.4%，规上工业增加值增长8.9%。宁波全体居民人均可支配收入7.78万元，接近全国平均水平的两倍。宁波工业里民营企业增加值占62.3%，民营企业进出口占全市进出口总额的77.9%。

为什么民营企业占比高对银行是巨大优势？因为贷款需求最旺盛、最需要金融服务的地方恰恰是民营和小微企业。国有大行服务大企业下沉做小微不划算，而宁波银行天生就是做中小企业的料。小微企业利率高、客户分散、单笔金额小，风险也被分散。摩根士丹利点名的"资产端投向中小微企业"，靠的就是这片土壤。

宁波银行的经营策略，公司自己概括成一句话：**"大银行做不好，小银行做不了。"** 长三角的中小企业和民营客户，大银行不是没能力做，是没动力做——单笔金额小、运营成本高；小银行想做，但资本、网点和科技投入不够。宁波银行卡在中间这个甜点位：规模够大，4万亿资产能摊薄科技和渠道成本，又不至于大到像大行那样被监管捆住手脚。

**但我把话说满之前，要泼一盆冷水：区域集中既是宁波银行的护城河，也是它最大的风险来源之一。** 浙江加江苏的85.84%，不是两个独立的鸡蛋——它们高度暴露于制造业、民营企业、外贸、房地产链和中小企业，这些是**高度相关的经济因子**。浙江出口好的时候江苏也差不了，外贸熄火的时候两个省一起熄火。所以更准确的说法是：**这是一个高质量、但高相关性的资产池。** 分散是假象，相关性才是本质。

### 支线二：多元化利润中心

先看一个数字：上半年手续费及佣金净收入43.17亿，同比增长53.90%。在息差收窄的行业大背景下，非息收入这么涨，靠的是什么？靠的是它**13个利润中心一起转**。

公司本部有9个利润中心：公司银行、零售公司、财富管理、消费信贷、信用卡、金融市场、投资银行、资产托管、票据业务。子公司还有4个：永银基金、永赢金租、宁银理财、宁银消金。

这13个利润中心，业内叫"多元利润中心模式"。实质是：不把银行的命压在净息差一条线上。息差降了，财富管理补；对公需求弱了，金融市场补；信贷风险高了，中间业务还在赚。

上半年三个板块的收入结构：公司银行业务营收178.33亿，个人业务109.97亿，资金业务122.18亿。三个引擎，任何一个熄火，另外两个还能兜底。

展开看子公司，这是宁波银行商业模式里最特别的一块。但我先纠正自己上次的一个说法——**别把这些子公司都叫"轻资本"。** 四家子公司，赚钱的方式其实是两种：

- **永银基金**（公募管理规模7571亿，其中非货5417亿，上半年净利5.22亿）、**宁银理财**（管理产品规模6563亿，上半年净利6.14亿）：这才是真轻资本。AUM上了规模，这些钱根本不在资产负债表上，不耗资本、不担信用风险，赚的是管理费。
- **永赢金租**（总资产1722亿，上半年净利16.69亿）、**宁银消金**（总资产730亿，上半年净利2.64亿）：本质还是信用业务、资产负债表生意。金租放大杠杆赚息差，消金放贷吃风险定价，都会消耗集团资本、承担信用风险。

所以永赢金租虽然是四家里"最赚钱"的，但要看清它是怎么赚的：按期末1722亿资产算，年化ROA大约1.9%——这是典型的靠规模和杠杆堆出来的利润，不是"空手套"。真正赚得"轻"的是宁银理财：6563亿AUM不上表，6.14亿净利几乎不占资本。

> 所以"13个利润中心"真正值得强调的，不是"全都不占资本"，而是**收入来源多元化——集团的命不再压死在存贷款息差一条线上**。这才比"轻资本"更准确。

子公司之外，看财富管理主业。截至6月末，宁波银行个人客户金融总资产（AUM）1.43万亿，比年初增加1543亿，半年增了12%。其中储蓄存款5726亿。私人银行客户3.4491万户，AUM 4206亿，**户均总资产1220万**——3万多个私行客户，人均在行里放了1000多万的资产。这个客户质量在城商行里是断层领先的。

财富管理对银行意味着什么？稳定的中间业务收入、客户粘性，更意味着低成本的沉淀资金。客户的钱留在你这，理财、活期、结算资金也跟着流下来。上半年活期存款占比35.57%，比年初提高1.14个百分点。

还是那句话：区域富，客户富，财富客户富，银行的轻资本生意才做得起来。支线一和支线二在这里咬合了。

### 支线三：负债端便宜，资产端干净

这一条直接决定银行的盈利质量。

先看负债端。上半年存款总额2.2948万亿，比年初增加2699亿，增长13.33%。更关键的是成本：存款付息率同比下降39个基点，活期存款占比35.57%（提高1.14个百分点），整体付息负债利率下降36个基点。翻译成人话：**宁波银行吸收资金的成本在显著下降。** 存款利率下行，它吃到了一大块。这在息差收缩的年代太重要了——资产端收益在降，但如果负债端成本降得更快，利差就能撑住。

再看资产端。上半年贷款平均收息率3.86%，其中对公贷款3.6%，个人贷款4.48%。这个收益率水平比很多同行高。而代价呢？不良率0.76%。高收益配上低不良，意味着它的信用成本低。摩根士丹利那句"显著的低信用成本与高净息差优势"，说的就是这个组合：低成本负债进来，高收益资产出去，中间是极低的坏账损耗。这是银行这门生意里最理想的形态。

## 第四部分：盈利增长到底来自哪里

这是这期我新加的一章，也是我认为最该问的问题。上半年营收414.50亿，增长11.54%，这个增速是怎么拼出来的？我拆成四层看。

**第一层：扩表撑着——量。** 贷款增速12.50%，总资产增速8.81%，都跑得比营收快。利息净收入293.94亿，增长14.26%——这里面相当大的部分是"以量补价"：量涨了12.5%，价（息差）在跌，净利息收入还能涨14%，靠的就是量。这一层最扎实，但它说明的不是"商业模式变好了"，是"生意做大了"。

**第二层：中收53.9%——质，但要拆开看。** 43.17亿的手续费净收入里，有媒体按半年报测算，代理类业务（代销基金、保险、理财、财富管理）占了约85%，同比增长约67%。也就是说，这波中收暴增几乎全部来自财富管理/代理业务。

那问题就来了：**这53.9%里，多少是结构性增长，多少是市场β？** 代销基金、代销保险的收入，随资本市场行情、居民风险偏好、基金销售周期大幅波动。如果未来市场转弱，AUM可能还在增长，但手续费增速未必还能保持50%+。所以准确的说法不是"宁波银行已经完成轻资本转型"，而是：**财富管理业务正在进入收获期，但它能不能成为长期稳定的高质量利润，还要继续观察。**

**第三层：成本——效率。** 业务及管理费112.61亿，几乎没增长，同比还微降0.19%。成本收入比27.17%，比去年同期大降3.19个百分点（去年中报还是30.36%）。收入增长11.54%、费用零增长，中间挤出来的全是利润。这是数字化转型的红利——APP个人用户1776万、企业客户43.61万，业务线上化不用堆人。

**第四层：也是这份中报最值得注意的信号——增长重心正在向对公移动。** 上半年公司贷款增长19.32%，个人贷款几乎原地踏步（5370.04亿，较年初只增0.47%）。

这里有两种完全不同的解读：

- **乐观版：** 宁波银行提前发现了零售风险，主动收缩个人贷款，把资源转向风险更低的优质对公客户。这说明管理层眼光好、动作快。
- **悲观版：** 个人贷款业务已经出现明显压力，只能收缩，未来增长越来越依赖对公。这意味着它"零售+小微+财富管理"的多元化，实际上正在某种程度的"再集中"。

我现在没法判断是哪个版本——这需要接下来几个季度观察。但有一个推论是确定的：**宁波银行正在变得越来越不像招商银行。** 招行是"零售+财富管理"；宁波如果继续对公化，会走向"对公小微+财富管理+综合金融"的组合。这个定位未必不好，但你必须意识到：你买的可能不是一个你原来以为的"零售银行"。

## 第五部分：财务体检——资产质量

宁波银行的资产质量，是全篇最需要仔细看的一块，因为好消息和坏消息都藏在这里。

### 先给一个框架：资产质量三角

看银行的资产质量，别只看一个数，要看三个：

| 指标 | 看什么 |
|---|---|
| 不良率 | 已经坏掉多少（结果） |
| 迁徙率 | 正在变坏多少（前瞻） |
| 信用成本 | 为这些风险付出了多少利润（利润表体现） |

三个数合在一起，才是一张完整的资产质量图。

### 总体：不良率和拨备都很漂亮

不良率0.76%，跟年初持平；拨备覆盖率373.35%，比年初提高0.19个百分点。连续19年低于1%。光看这两个数，宁波银行是银行业最干净的资产表之一。还有一个更惊人的数：对公贷款不良率只有0.23%——贷给企业的钱，99.77%都收得回来。这是2025年末的口径，方向上可信。

### 迁徙率大降——但别只看这一个数

最能说明"增量在改善"的是迁徙率：正常类贷款迁徙率，去年同期2.53%，今年上半年只有0.98%；关注类从35.13%降到30.76%；可疑类从90.28%降到36.24%。贷款恶化的速度，比去年慢了一大截。

但我要给自己提个醒：**迁徙率下降，不等于最终信用风险一定下降。** 银行处理坏账的出口不止一条——核销、转让、重组、清收，都会让"已经变坏的贷款"不再出现在迁徙统计里。宁波银行的重组贷款2025年末是57.36亿元，规模曾经明显上升。所以更严谨的表述是：**迁徙率改善，需要结合核销、重组和逾期率一起看，不能只看五级分类迁徙率一个数。**

### 信用成本：不是"藏利润"，是"审慎确认"

上半年信用及资产减值损失115.77亿，同比增加22.25亿，增长23.79%。这个增速超过了营收和利润的增速。

上次我在这里用了"藏利润"的说法。这次我改口，因为证据不够支持这个词。

公司自己的解释很明确：主要是贷款规模增长带动贷款减值损失同比增加。贷款减值损失增加22.63亿，增长26.35%。拆开算：贷款规模只增了12.5%，但贷款减值计提增了26.35%——如果只是"规模大了就多计提"，两个数应该差不多。26%明显快于12.5%，说明**每单位贷款的信用成本在上升**。

粗算信用成本：上半年贷款减值损失约108.5亿（按增速反推），平均贷款约1.84万亿，年化信用成本约1.2%。而它换来的是不良率持平、拨备覆盖率还提高了0.19个百分点。

所以准确的结论是：**宁波银行在做"审慎的风险成本确认"——在盈利高增长年份多提拨备、增厚安全垫。** 这本身不是坏事，但你别把它理解成"利润有水分"，也别当成"资产质量没在变化"。计提增速跑赢规模增速这件事本身，就是一个需要继续盯的信号。

### 个贷不良率——全文最该盯的地方

终于说到最关键的一块。全行不良率0.76%，很漂亮。但拆开看，有一个数在持续往上走，跟全行形成了刺眼的反差：

**个人贷款不良率：1.94%。**

拆开结构：
- 个人消费贷不良率1.85%
- **个体经营贷不良率3.45%**
- 个人住房贷不良率0.89%

更值得警惕的是趋势——这个指标一直在往上走，几乎没停过：

| 年度 | 个人贷款不良率 |
|---|---|
| 2022 | 1.39% |
| 2023 | 1.50% |
| 2024 | 1.68% |
| 2025 | 1.94% |

四年，从1.39%爬到1.94%。而同一时间，全行不良率稳定在0.76%左右。

所以真正值得问的问题不是"宁波银行不良率为什么这么低"，而是：**为什么全行不良率这么低，个人贷款不良率却持续上升？**

答案是结构：宁波银行的资产大头在低风险的对公（对公不良率0.23%），个贷占贷款总额约27%，它内部的裂缝被对公的铁壁盖住了。但裂缝本身没有消失——个体经营贷3.45%的不良率，说明小微和个体经济在承压。宁波本地不良率1.33%也明显高于全行，正是因为本地是它做小微和个体经营贷的主战场。

结合第四部分的"个贷规模只增0.47%"：宁波银行正在主动或被动地收缩零售。如果这是主动风控，管理层优秀；如果是被动承压，那"多元化"正在缩水成"对公化"。**这是未来2到3个季度最需要跟踪的信号：个贷不良率能不能见顶。**

### 地区不良率结构

全行0.76%拆开：浙江省占62.60%，不良率0.75%；江苏0.74%，广东0.67%，上海0.94%，北京0.93%。宁波本地占28.13%，不良率1.33%，明显高于全行。占六成多的浙江省，靠省内其他地区的极低不良率（大约0.28%）把整体拉了下来。

宁波本地不良率为什么高？因为本地是它做小微和个体经营贷的主战场，这类业务天然不良率高于大企业对公。这个1.33%不是风险失控，是客群结构的体现。

但作为看空逻辑，必须把这个点摆出来：如果宁波本地的小微经济继续承压，1.33%可能继续往上走，拖累全行。这就是85.84%区域集中风险的具体落点——护城河和风险，是同一枚硬币的两面。

## 第六部分：资本充足率——阶段性缓解，≠证伪

上次我提过一个风险：核心一级资本充足率连续下降，可能制约扩张。当时的数字是9.34%，确实在降。

这次中报：核心一级资本充足率9.53%，比年初回升0.19个百分点；一级资本充足率11.16%，回升0.76个百分点；资本充足率14.64%，回升0.34个百分点。看起来全线回升。

但我必须指出关键一点：**回升的主要来源，是上半年发行的160亿元永续债。** 永续债补的是"其他一级资本"——所以你看一级资本充足率回升了0.76个百分点，而真正卡脖子的核心一级资本，只回升了0.19个百分点。

所以结论要改：**资本约束是"阶段性缓解"，不是"被证伪"。** 贷款还在以12.5%的速度扩表，核心一级资本只微升0.19个百分点，说明内生资本只是勉强跟上扩张。真正的考验是：如果扩表持续、而盈利增速掉到个位数，核心一级资本还会往下走。

## 第七部分：行业背景

宁波银行不是活在真空里。监管口径的数据显示，商业银行净息差出现了止跌企稳的迹象。2026年二季度，行业净息差首次出现单季环比回升。券商研报的说法是："息差企稳回升，扩表减量提质。"

这对宁波银行意味着什么？它最担心的变量——息差——可能正在见到阶段性的底部。它的净息差降幅已经小于行业，如果行业拐点确认，它会是第一批受益者。当然，单季环比回升一个季度还不能叫趋势确立，但方向值得重视。

## 第九部分：到底值多少钱

### 三件套现状

当前价34.18元，总市值2257亿（涨完3.64%之后的价格）。

- **PE(TTM) 7.25倍**，上市以来PE分位大约28%~30%——比它历史上七成的时间都便宜。
- **PB 0.80倍**，每股净资产42.94元——花八毛钱买一块钱的账面净资产。
- **股息率3.51%**（2025年度每股派1.2元），近3年累计分红加回购178.30亿，占年均净利润的65.23%。今年中期又宣布每十股派4元，占上半年净利润的15.95%。

### 关键问题：0.8倍PB到底便不便宜？取决于ROE能不能撑住

上次我简单地说"14.24%的ROE配0.8倍PB，明显不匹配，合理PB应该在1.3倍左右"。这句话太粗糙了。银行的合理PB不是"ROE乘个常数"，而是三个变量的函数：

**合理PB ≈ (ROE − g) / (COE − g)**

其中g是长期增长率，COE是股东要求回报率（资本成本）。用这个公式做情景，COE统一按10%算：

| 情景 | ROE | 长期增长g | 合理PB | 对应股价（×42.94） | 0.8倍PB贵不贵 |
|---|---|---|---|---|---|
| 悲观 | 8% | 3% | 0.71 | 30元 | 不便宜，甚至有点贵 |
| 悲观 | 10% | 3% | 1.00 | 43元 | 便宜 |
| 中性 | 11%~12% | 4% | 1.17~1.33 | 50~57元 | 明显便宜 |
| 乐观 | 13%~14% | 5% | 1.60~1.80 | 69~77元 | 很便宜 |

看清楚这个表的含义：**"0.8倍PB便宜"这个结论，整个建立在"ROE能维持10%以上"的前提上。** 如果ROE死到8%，0.8倍PB非但不便宜，反而是市场定价精准，甚至有点贵。这就是这篇的主线：宁波银行真正的生死线不是不良率，是ROE能不能长期站在10%以上（我自己的标准是12%以上才算稳）。

（顺便说，这也是"剩余收益"模型的本质：公司价值 = 账面净资产 + 未来每年"ROE超过资本成本的部分"的现值。ROE≥COE，PB就能站上1；ROE<COE，PB就该跌破1。上面那个公式就是它简化后的样子，不需要再单独跑一遍DCF。）

### 极端压力测试：买34.18，最坏能亏多少

上次我的"底线思维"有个逻辑漏洞：我说"假设ROE跌到10%，底线股息率还有3.1%，能跑赢国债"。这个假设站不住——**如果ROE真的跌到10%，市场不会还按0.8倍PB给价，PB会一起跌。** 下面才是诚实的压力测试：

- 如果PB跌到0.6倍：股价 = 42.94×0.6 = **25.76元**，从34.18买入，**回撤24.6%**。
- 如果PB跌到0.5倍：股价 = 42.94×0.5 = **21.47元**，**回撤37.2%**。

所以真实的"安全边际"不是"现在3.1%股息率跑赢国债"，而是：**你愿不愿意为"ROE不崩"这个判断，承担最多三成多的回撤。** 买宁波银行，本质上是买"ROE能守住"，而不是买"不良率低"。

### 3~5年到底能赚多少：三种情景粗算

上次我说"适合3到5年去兑现"，但没算账。这次补上。用4年左右做粗算，假设：BVPS每年按 ROE×(1−分红率) 增长（留存利润滚进净资产），分红率中性按27%算，股息累计计入回报、不复投。

| 情景 | ROE | PB终值 | 4年后股价 | 4年累计股息 | 总回报 | 年化 |
|---|---|---|---|---|---|---|
| 悲观 | 10% | 0.6 | 34元 | 约5元 | 约+14% | 约3% |
| 中性 | 12% | 0.9 | 54元 | 约8元 | 约+83% | 约15% |
| 乐观 | 13.5% | 1.0 | 62元 | 约10元 | 约+110% | 约20% |

中性那档我摆给你看怎么算的：BVPS现在42.94元，ROE 12%、分红率27%，留存的73%按12%滚存，BVPS每年涨约8.8%。四年后BVPS约60元，市场给0.9倍PB就是54元。加上四年股息约8元，总共从34.18变成约62元，年化约15%。

悲观档的教训是：ROE掉到10%、PB掉到0.6，股价基本横盘，你拿四年只能赚个股息——不亏，但也没赚到钱。**这就是"ROE下行"的真实代价。**

一句话总结估值：**34.18元不贵，但"便宜"两个字后面挂着一个大前提——ROE不下行。** 中性情景年化15%左右，值得买；如果它未来三年ROE死到8%以下，0.8倍PB就是价值陷阱。

### 股东回报：一个被忽视的看点

把"ROE→留存→BVPS→分红"这条链串起来，会发现一个有意思的地方。宁波银行现在PB<1（0.8倍），这意味着：**每留存1元钱进资产负债表，市场只认0.8元——理论上，回购自己的股票，比扩大资产规模更划算。** 很多高股息的银行股都在提高分红率或回购，宁波银行目前分红率约27%，在城商行里不算高。

它没这么做，是因为它仍把自己定位成"成长股"——利润留着扩张，去赚ROE 14%的钱，而不是分出去。这个选择对不对，取决于ROE能不能维持。**如果哪天真看到宁波银行大幅提高分红率或启动回购，那是一个值得重估的信号：管理层自己认为成长天花板到了。** 它既是利空信号（成长性打折），也是利好种子（股东回报提升）——到时候要重新算这笔账。

## 第十部分：未来三年靠什么增长——ROE生命线

### 三条增长路径

宁波银行未来三年靠什么增长，决定了ROE走向。大致三条路：

**A. 继续扩表。** 贷款保持12%~15%增长，利息收入靠量撑。问题：资本压力越来越大（核心一级资本9.53%，扩表12.5%时内生资本只勉强跟上），而且息差还在跌，扩表效率在递减。

**B. 财富管理。** AUM增长 → 中收增长 → 低资本消耗。这是最理想的路，也是今年中收+53.9%在暗示的方向。但要警惕市场β：中收增速能不能稳住，一半取决于资本市场行不行。

**C. 提高资本效率。** 同样的资本赚更多的钱，这是ROE的最终来源。宁波银行的优势靠"低成本负债+低信用成本"，这两条目前都在。

我的判断：宁波的真实路径是A+B+C的组合——对公扩表维持规模基本盘，财富管理提供中收和低成本沉淀存款，资本效率决定ROE的上限。三条里任何一条熄火，ROE都会掉档。

### 估值生命线（我给自己定的跟踪表）

下面这些阈值是我粗定的，不是真理，每出一份季报都要对照着校准一次：

|---|---|---|---|
| ROE | 14.24% | <12% | <10% |
| 净息差 | 1.70% | <1.55% | <1.40% |
| 全行不良率 | 0.76% | >0.90% | >1.10% |
| **个贷不良率** | 1.94%（2025末） | >2.3% | >2.8% |
| 核心一级资本 | 9.53% | <9.0% | <8.5% |
| 中收增速 | +53.90% | <10% | 转负 |
| PB | 0.80 | <0.65 | <0.55 |

每一个季度财报出来，我只关心三件事：**ROE是不是还在12%以上、个贷不良是不是还在涨、中收增速是不是掉到个位数。** 这三个变量同时健康，34.18元就是便宜的；任何一个恶化，都要重新问"0.8倍PB到底便宜不便宜"。

### 这篇真正的主线

如果你只记住一句话，记这句：

> **宁波银行真正的投资逻辑，不是0.76%的不良率，而是它能不能在息差长期下行的时代，靠低成本负债、对公业务优势和财富管理增长，把ROE长期维持在12%以上。**

不良率是它的历史，ROE才是它的未来。

---

## 第十一部分：风险清单

**第一，ROE下行。** 这是生死线。2023年15.08%→2024年13.59%→2025年13.11%，连续两年下行，今年半年回升到14.24%。一个半年回升不能断定拐点。如果ROE持续向12%以下走，"0.8倍PB便宜"的假设就塌了。跟踪锚：每个季度加权ROE。

**第二，息差。** 净息差1.70%还在降。如果行业息差企稳被证伪、继续单边下行，利润增速会明显放缓。跟踪锚：净息差环比。

**第三，个贷不良率。** 1.94%且四年连升，其中个体经营贷3.45%。这是全行0.76%下面最刺眼的裂缝。如果它继续升破2.3%，就要重新审视零售这条线。跟踪锚：个贷不良率，以及它跟个贷规模增速的关系。

**第四，区域集中。** 85.84%压浙江江苏，高质量但高相关性。单一区域经济失速，护城河立刻变软肋。跟踪锚：浙江江苏GDP、外贸数据、宁波本地不良率1.33%。

**第五，中收的市场β依赖。** 中收+53.9%很好看，但八成五是代理业务，随资本市场波动。市场转弱，中收增速可能迅速掉回个位数。跟踪锚：每季度手续费增速，以及非代理类收入占比。

**第六，资本约束阶段性缓解≠解除。** 160亿永续债补的是其他一级资本，核心一级只微升。扩表不停、盈利增速掉档，核心一级还会下探。跟踪锚：核心一级资本充足率 vs 贷款增速。

**第七，估值修复不确定。** PB 0.8倍"便宜"可以维持很久，市场对银行的悲观不是一天形成的，修复需要催化剂。跟踪锚：PB分位、分红率/回购动向。

这七条，任何一条恶化都值得重新审视。投资最怕的不是风险多，是看不见风险。

## 第十二部分：回答开头的两个问题

**第一个问题：摩根士丹利评的"最佳商业模式"成立吗？**

成立，但要看清成立的边界。三条支线——长三角的优质土壤、13个利润中心的多元结构（准确说是"收入来源多元化"）、低成本负债加低信用成本——每一条都在中报里找到了对应的证据。但"最佳商业模式"评的是它的**结构**，不是它的**未来**。结构是真的好，而ROE能不能维持、个贷不良能不能见顶，是中报回答不了的问题，只能用接下来的季度去验证。

**第二个问题：34.18元贵不贵？**

我的答案，比上次保守半格：**优秀银行 + 合理偏低的估值 + ROE下行风险仍需验证。**

不贵——中性情景4年年化约15%，悲观情景也不至于亏本金（约3%），有股息托底。但也谈不上"闭眼买"——悲观情景下你要承受最多三成多的回撤，而"便宜"的前提（ROE≥10%）既没被证伪，也没被证实。市场的逻辑很简单：它用0.8倍PB定价了"宁波银行未来ROE会掉"，你要买，就是在赌"不会掉，甚至能稳住12%以上"。这笔赌注的赔率不算差，但请清楚你在赌什么。

最后说句实在话：**不要预测宁波银行会不会涨，去预测它未来三年能不能维持12%以上的ROE。** 这个问题答对了，34.18到底便不便宜，答案自然就有了。

---

把上一版附录里那段"巴菲特视角"作为收尾框架，融进来：巴菲特说，银行是好生意，前提是找到一家管得好、估值合理的银行。管得好——连续19年不良率低于1%是证据；估值合理——0.8倍PB，但前提是ROE能维持。但巴菲特还有另一句：**"只有当潮水退去，你才知道谁在裸泳。"** 对宁波银行，潮水就是息差和零售周期。它现在穿着衣服，但你要盯着那件衣服有没有变薄——每个季度看一次ROE、个贷不良和中收，就够了。

## 下篇：兴业银行——同一把尺子量出来的另一面

宁波那篇写完了，现在轮到兴业。为什么要特意把这两家放一起？因为它们在同一把尺子上，站在完全相反的两端：**宁波是"贵一点的好银行"（0.8倍PB），兴业是"便宜到极点的争议银行"（0.46倍PB）。** 看明白这两家的对比，比看任何一家单独的估值分析，都更能理解"银行股到底该给多少倍PB"。

先说数据时点，这是最要紧的：**兴业的中报还没发（预计8月28日披露）。** 所以这篇用的是2025年年报加2026年一季度的数据——比宁波那篇旧一个季度。我不打算等中报，因为分析的价值在于先手：等中报出来，市场早就反应完了。这篇先立个基线，中报出来再对照更新。

## 一、认识这家银行：股份行里的"另一个极端"

兴业银行（601166），股份行，总部在福州，福建国资背景——福建省投资开发集团最近连续两个季度增持，持股升到2.86%。总资产11.09万亿（2025年末），股份行里排第二，仅次于招商银行。

它曾经有个历史标签叫"**同业之王**"——早年靠同业和资金业务把规模做起来。但我要先说一句：**这个标签正在过时。** 2025年的兴业正在明显"脱同业化"，这件事我放到商业模式那节展开。它现在的样子，和2021年市场记忆里的"兴业"，已经不是同一家银行了。

同样是两市里的银行，它和宁波站在光谱两端：宁波是"小而美"，兴业是"大而便宜"——**大到11万亿资产，便宜到只值3850亿市值。**

## 二、最新财报：2025年报 + 2026Q1

先把数字过一遍。

**2025年报（2026年3月底披露）：**
- 归母净利润774.69亿，**同比只增0.34%**；扣非770.64亿，增0.38%。营收2127.41亿，增0.24%。
- **ROE 9.15%**，同比下降0.74个百分点——这是兴业和宁波之间最刺眼的差距（宁波14.24%）。
- 净息差1.71%，同比下降11个基点，"四连降"。2026年一季度再降到1.62%。
- 不良率1.08%，拨备覆盖率228.41%（还降了9.37个百分点）。
- 分红：每10股派10.66元（中期5.65+末期5.01），分红总额225.60亿，**现金分红比例首次突破30%**（31.02%）。按现价18.21元算，股息率约5.9%。
- **一个很多分析不看的数：拨备前利润（PPOP）1475.70亿，而净利润只有774.69亿。** 中间差了700亿——这700亿，就是风险成本。这句话先记着，第四节会用到。
- 核心一级资本充足率9.70%（2025年末），一季度降到9.50%。

**2026年一季度（4月底披露）：**
- 营收550.90亿，同比-1.06%；归母净利238.32亿，同比+0.15%——**收入在缩、利润勉强持平**。
- 不良率1.08%持平，但**关注类贷款率升到1.75%**（上升6~7个基点，主因是零售贷款风险波动）。
- 拨备覆盖率降到224.52%。
- 中收+7.4%，其中财富中收+17.5%、托管中收+11.8%——这是难得的亮点。
- 一季度新增贷款超2060亿，接近去年全年增量，信贷"开门红"。

## 三、商业模式：它正在"脱同业化"

宁波的商业模式，靠的是"长三角最肥的土壤+对公小微+财富管理"；兴业没有这个区域稀缺性，它靠的是另三样东西。但先说清楚：**你现在用"同业之王"去概括兴业，已经落后了。**

看2025年的负债端变化，兴业在做一件很重要的事——把负债从"同业资金"换成"低成本存款"：

- 2025年存款余额5.93万亿，同比增长7.18%；**存款付息率降到1.65%，同比下降33个基点。**
- 拆开看更明显：**企金存款从3.31万亿增加到4.13万亿，零售存款从0.73万亿增加到1.80万亿**——零售存款翻了一倍还多。

这意味着兴业的钱，越来越来自"客户的钱"而不是"市场的钱"，负债成本在实打实地降。2026Q1存款付息率进一步降到1.44%，同比降35个基点。这正是它息差还能撑在1.6%的原因——负债端替资产端挡了一刀。

资产端也在变。2025年贷款整体只增3.70%，但结构明显在换血：
- **制造业贷款 +14.91%**
- **科技金融贷款 +18.47%**
- **绿色贷款 +19.05%**
- **全国重点行业贷款 +20.1%**

而市场最担心的那三个领域——**房地产、地方政府融资平台、信用卡——新发生不良全部同比回落**（2025年报官方口径）。

这一堆数字合起来，我只看到一件事：**兴业正在做资产结构迁移——把当年压垮它估值的旧资产，换成监管鼓励、收益率和安全边际都更好的新资产。** 市场对兴业的印象还停在2021~2022年那个"房地产+同业之王"，但数据表明它已经不是那家银行了。**这可能是兴业最大的预期差。**

中间业务也在补课：兴银理财规模居前，绿色金融是行业先行者，同业合作、债券承销、资产托管、银行理财在股份行里都排前列。2026Q1中收+7.4%，其中财富中收+17.5%、托管+11.8%。但整体看中收占比还薄——2025年利息净收入1487.52亿，占营收七成，收入结构仍偏重息差。

最后说规模经济。11万亿资产既是拖累（ROE被摊薄），也是资产：科技投入可以摊薄、金融市场和投行资源强、托管和理财规模大、大型企业客户覆盖广。**如果资产质量改善+负债成本下降+非息收入增长+大规模业务的经营杠杆释放，四件事凑齐，11万亿资产的盈利效率可能发生改善——这才是兴业真正的戴维斯双击剧本。** 但"如果"两个字意味着，一切还没兑现。

一句话：**宁波赚的是"区域+小微+财富"的精品钱，兴业赚的是"全国对公+产业金融+大财富"的规模钱。** 前者毛利高、坏账低；后者毛利薄，但正在用负债端和资产端两个方向的换血，把利润率往回拽。

## 四、为什么ROE只有9.15%？（杜邦拆解）

这是我最想补的一节。宁波14.24%，兴业9.15%，**这5个百分点的差距到底去哪了？** 只有拆开，你才知道兴业到底是"不行"，还是"暂时被风险成本压着"。

先看息差——你会很意外：**兴业净息差1.71%，宁波1.70%，几乎一样。** 所以兴业ROE低，根本原因不是息差比宁波差。

再用杜邦拆解看：**ROE ≈ ROA × 权益乘数。**
- 兴业：ROA只有0.72%（2025），权益乘数约13倍（11.09万亿资产/约8400亿净资产），0.72%×13≈9.4%，对得上9.15%。
- 宁波：ROA粗算约1.0%（年化口径），权益乘数约14倍，1.0%×14≈14%，对得上14.24%。

**杠杆两家都放大了十三四倍，都是典型的高杠杆生意。差别全在ROA——同样是1万亿资产，宁波能生出1亿的利润，兴业只能生出0.72亿。** 这才是"为什么11万亿资产只值3850亿市值"的答案：不是资产不够大，是这么大的资产，创造出来的利润率不够高。

ROA为什么差这么多？三个原因，按重要性排：

**第一，风险成本吃掉一大块利润。** 这是最关键的一个数：兴业2025年拨备前利润（PPOP）1475.70亿，扣完风险成本之后净利润只剩774.69亿——**赚的钱有将近一半要拿去覆盖风险成本。** 宁波不需要拿这么多。这也是为什么兴业ROE只有9%，而不是12%。

**第二，费用率偏高。** 兴业2025年成本收入比29.56%，宁波约27%。规模大的银行往往人海战术重，费用吃掉一部分利润。

**第三，生息资产收益率偏低。** 兴业的资产里同业和资金业务的历史占比高，这部分资产收益率天生比贷款低，把整体资产收益率往下拖。负债端降成本省下来的钱，有一部分被资产端低收益率吃回去了。

所以"兴业ROE低"要拆成两半看：**一半是它资产结构的历史包袱（同业资产、房地产、城投），另一半是风险成本压的。** 前者正在靠资产迁移慢慢化解，后者能不能降，取决于资产质量。下一节说完资产质量，这两半到底哪一半能修好，你自己就有判断了。

## 五、资产质量：市场在担心什么

兴业的估值被压到0.46倍PB，市场在担心三件事。这三件事是真的，但答案可能比"地产城投会不会爆"更精细。

**第一件，房地产。** 兴业历史上房地产敞口在股份行里是偏高的，这是它估值最大的包袱。2026年一季报有一个积极的表述：**对公房地产新发生不良，同比回落。** 但我要给自己提个醒：**"新发生不良回落"只能证明边际改善，不能证明风险出清。** 要真正验证房地产风险，光看新发生不良不够，还得盯逾期、关注、重组、核销、不良生成率一整套指标。地产的完整敞口也不只是房地产开发贷——对公房地产、个人按揭、非标、债券、资管产品、表外，都在里面。这块是8月28日中报要重点核对的。

**第二件，城投（地方政府融资）。** 一季报表述是"地方政府融资资产质量稳定"。意思是没爆，但也没有还上的证据。城投债承销、非标、资产管理计划这些表内外敞口，都要看。这块我不提前下"靠展期置换续命"这种判断，因为没有数据支撑；我只把它列为"需要持续验证、目前稳定"。

**第三件，信用卡和零售。** 关注类贷款率升到1.75%，官方明确主因是零售贷款风险波动。这一块跟宁波"个贷不良1.94%连升"是同一种病——**整个银行业的零售都在还前几年扩张的债。**

但这里有个比"地产城投会不会爆"更精准的前瞻信号，我建议你盯这个：**关注类贷款率的趋势。**

| 年度 | 关注类贷款率 | 不良率 |
|---|---|---|
| 2023 | 1.55% | 1.07% |
| 2024 | 1.71% | 1.07% |
| 2025 | 1.69% | 1.08% |
| 2026Q1 | 1.75% | 1.08% |

看出来没有？**不良率一直很稳（1.07→1.08），但关注类在2023到2026Q1之间上蹿下跳、整体抬升。** 关注类是"还没坏但可能变坏"的贷款，它是不良率的前瞻指标。兴业真正要防的，不是"不良已经爆发"——而是**关注类继续向不良迁徙。** 如果关注类一路走到2%以上，不良率迟早会被拖上去。这才是兴业资产质量最该盯的那个数。

对比看宁波：宁波不良率0.76%、拨备373%，兴业不良率1.08%、拨备228%。同样是"便宜"，两家的资产质量完全不是一回事。**宁波的便宜，是市场对"ROE能不能维持"存疑；兴业的便宜，是市场对"资产质量能不能持续改善"存疑。** 但注意，这句已经比上一版更精确了——兴业的问题不是"会不会爆雷"，而是"改善能不能兑现"。

## 六、估值：0.46倍PB的"便宜"靠什么撑

先看现在什么价。2026年8月26日，兴业收盘18.21元，总市值3854亿，PE(TTM)约5.0倍，PB约0.46倍，每股净资产约39元，股息率约5.9%。

用宁波那篇的公式：合理PB ≈ (ROE−g)/(COE−g)。**但先说清楚，这个公式算出来的，是"在给定ROE、增长率和资本成本假设下的合理PB"，它不是客观真理，所有数字都依赖假设。** 兴业账面ROE 9.15%，代进去做三情景：

| 情景 | ROE | g | COE | 合理PB | 对比现在0.46 |
|---|---|---|---|---|---|
| 悲观 | 7% | 2% | 11% | (7−2)/(11−2)≈0.56 | 不算特别便宜，有一点安全边际 |
| 中性 | 9% | 3% | 10% | (9−3)/(10−3)≈0.86 | 明显低估 |
| 乐观 | 11% | 4% | 10% | (11−4)/(10−4)≈1.17 | 巨大修复空间 |

反过来算：**在假设COE为10%、长期增长率为3%的情况下，0.46倍PB对应的隐含长期ROE约6.2%**（0.46×7%+3%）。也就是说，市场现在的定价，等于在赌"兴业未来长期只能赚6%出头的ROE"——比它现在9.15%的账面ROE低不少，比"制造业+科技+绿色贷款正在快速换血"之后可能达到的水平更低。

这就是兴业的全部争论，两个解读：

- **解读A：市场过度悲观。** 如果资产迁移兑现、风险成本下降，ROE稳住甚至回升，0.46倍PB就是被错杀。
- **解读B：市场是对的。** 地产城投和信用卡的风险还没兑现，但市场可能已经提前给未来更低的ROE定价了。

我不能替市场裁决哪个对，但可以说清楚：**买兴业，赌的不是"地产城投永不爆雷"这种极端假设，而是"资产结构迁移能兑现、ROE能修复"。** 这和宁波赌"高ROE能维持"是两回事——宁波的变量是盈利质量能不能守住，兴业的变量是ROE能不能往上走。

三情景粗算回报（4年，股息按分红率31%估算）：

| 情景 | 前提 | 年化回报 |
|---|---|---|
| 悲观 | 资产质量恶化，ROE 9%→7%，分红缩水 | 约2~4%，可能只拿股息 |
| 中性 | 资产迁移兑现但慢，ROE稳在9%，分红维持 | 股息约5.9% + 净资产滚存，约10~12% |
| 乐观 | 风险成本下降，ROE回到10~11%，PB修复到0.6+ | 股息 + 估值修复，约15%以上 |

中性那档的逻辑：你花0.46元买1元净资产，这1元净资产每年赚9分钱（ROE 9%），其中约3分发给你（分红率31%）。只要"每年9分钱"能维持，你拿到的就是股息加净资产滚存，年化10%出头——比国债（1.7%）好太多。**但请务必记住一条：5.9%的股息率是现金缓冲，不是本金安全垫。** 如果ROE掉到7%、分红率也跟着降，股息率会迅速缩水；如果PB再从0.46跌到0.38（股价从18.2元跌到15元），你拿到手的股息，填不上账面亏损。股息是"靠时间等回报"的策略，不是"买了就锁死收益"的策略。

## 七、兴业 vs 宁波：同一把尺子，两个答案

先提一个比较原则：**两家数据截止日不同（宁波2026H1已出，兴业2026Q1/2025A），下面的盈利增速不能直接横向比较，只能看方向。** 等兴业中报出来、口径统一了，再下精确结论。

| 维度 | 宁波银行 | 兴业银行 |
|---|---|---|
| 类型 | 城商行 | 股份行 |
| 净利增速 | +12.12%（2026H1） | +0.34%（2025A）/ +0.15%（26Q1） |
| ROE | 14.24% | 9.15% |
| ROA | 约1.0%（粗算） | 0.72% |
| 净息差 | 1.70% | 1.62%~1.71% |
| 不良率 | 0.76% | 1.08% |
| 拨备覆盖率 | 373.35% | 228.41% |
| 核心一级资本 | 9.53% | 9.50%（26Q1） |
| 中收增速 | +53.90% | +7.4%（26Q1） |
| PB | 0.80 | 0.46 |
| 股息率 | 3.51% | 约5.9% |
| 分红率 | 约27% | 31.02% |
| 市场担心的 | ROE能不能维持12%+ | ROE能不能修复回10%+ |
| 核心变量 | 息差（NIM） | 信用成本 |
| 关键资产 | 小微/对公+财富 | 对公+地产/城投+零售 |
| 投资类型 | **质量+成长** | **困境反转+股息** |

这张表读透，就是这篇的全部结论：

**两家都是"便宜"的银行，但便宜的原因和投资逻辑完全不同。**

**宁波，是"高ROE维持型"投资。** 你在买一个已经被证明的优秀商业模式，赌的是14.24%的ROE能继续维持。它便宜（0.8倍PB），是因为市场不信"好"能持续；你赚钱的路径，是ROE继续滚存+利润增长把估值填平，中性情景年化约15%。它最大的风险不是别的，就是ROE掉下来——14%→12%，市场会立刻给你估值压缩。

**兴业，是"低PB+ROE修复型"投资。** 你在买一个尚未被重新定价的修复空间，赌的是风险成本下降、ROE从9.15%回升到10%甚至11%。它便宜（0.46倍PB），是因为市场用"未来长期ROE只有6%"来定价；你赚钱的路径，是ROE修复（哪怕只回到9%以上）带来的估值扩张+吃股息，中性情景年化约10~12%。它最大的风险，是修复不兑现——ROE继续掉，那0.46倍PB就不是"市场错了"，而是市场看得比你远。

所以别问"哪个便宜买哪个"——**这不是同一个"便宜"。** 宁波要问的是"14.24%的ROE还能保持几年"，兴业要问的是"9.15%的ROE能不能回到11%左右"。这两个问题回答出来，0.8和0.46谁更值得买，答案自然就出来了。

我的态度（诚实版）：单看盈利质量和确定性，宁波明显更强；但兴业有一个宁波没有的东西——**修复的期权**。0.46倍的PB，把"资产迁移兑现、ROE回升"的预期压得很低，一旦兑现，赔率很大。反过来，如果兴业的中报证明ROE还在往下掉，这个期权就归零。**宁波是"高确定性低赔率"，兴业是"低确定性高赔率"——你要哪一种，是你自己的选择，不是我的建议。**
