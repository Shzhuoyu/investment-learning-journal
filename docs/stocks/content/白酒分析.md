# 年轻人不喝白酒？别扯了！白酒真正的问题在这里

> **摘要**：本文不分析个股，仅探讨白酒行业。核心结论前置：**我不看好当前高PB估值下的白酒**。原因并非“年轻人不喝白酒”，而是基于芒格投资框架下的深层逻辑——高ROE无法再投资，叠加高PB估值，导致长期实际回报被严重稀释。
>
> ⚠️ **免责声明**：以上分析基于公开数据，不构成投资建议，决策需自主。

## 一、 破除迷思：“年轻人不喝白酒”是个伪命题

市场上流行一种说法：“年轻人不喝白酒了，白酒要完。”这个逻辑链从起点就是断的，因为它把**阶段性的年龄特征**误判为**长期的品类消亡**。

-   **历史规律**：每一代人年轻时都不喝白酒。18岁喝啤酒，25岁喝精酿或威士忌，白酒从来不是20岁时的首选。
-   **场景驱动**：白酒是30岁以后伴随商务宴请、婚丧嫁娶等社交场景才登上餐桌的。
-   **代际轮回**：今天90后不喝白酒，与20年前70后年轻时不喝白酒是同一个现象。人到中年，消费场景改变，白酒自然上桌。

因此，用“年轻人不喝”来预测白酒消亡，在方法论上就是错误的。**白酒的真正问题，不在于没人喝，而在于另一件更反直觉的事。**

## 二、 理论基石：芒格的“长期回报”公式

查理·芒格在《穷查理宝典》中说过一段经典的话：

> “长期来看，一只股票很难获得比它背后业务更高的回报。如果企业40年赚6%的资本回报率，你持有40年，就算买入时打了很大折扣，回报也差不多是6%。反过来，如果企业赚18%，即使买贵了，二三十年下来结果也会非常惊人。”

这句话揭示了一个反直觉的道理：**长期回报不取决于你买得多便宜，而取决于企业自身的赚钱能力（ROE）。**

### 被忽略的隐含前提

芒格这句话有一个至关重要的前提：**企业赚到的钱，必须能够以同样的ROE再投资回去。**

-   **理想情况**：B店ROE 18%，每年赚18万，能开新店且新店也是18% ROE → 利润复利增长 → 长期回报=18%。
-   **现实困境**：若市场饱和无法开店，赚到的钱只能分红或买理财。
    -   **分红**：实际回报率 = ROE ÷ PB（买入市净率）。
    -   **买理财**：低收益理财拉低综合ROE。

**结论**：如果不能再投资，`长期回报 ≈ ROE` 就不成立。

## 三、 框架检验：白酒满足芒格的三个要素吗？

我们将芒格的逻辑提炼为公式：
$$长期回报 \approx ROE \times 再投资能力 \div PB$$

### 1. 要素一：企业自身ROE高不高？
**完全满足**。白酒是A股顶级的好生意。

| 指标 | 数据表现 | 备注 |
| :--- | :--- | :--- |
| 毛利率 | 82.34%（行业平均） | 卖100元成本不到18元；茅台自身约92%，成本不到9元 |
| 净利率 | ~35%（行业平均） | 盈利能力极强；茅台自身约50% |
| 头部ROE | >30% | 茅台、汾酒、泸州老窖等头部持续保持 |
| 现金流 | 优异 | 无需大量资本开支 |

### 2. 要素二：赚到的钱能以同样高ROE再投资吗？
**完全不满足**。这是白酒真正的“病根”。

-   **海外扩张失败**：茅台2024年海外营收占比不足3%，且多为华人消费。文化壁垒+高关税，导致出海十几年毫无突破。
-   **国内市场饱和**：2025年全国白酒产量同比下降12.1%（规上口径），2026年预计继续下滑。行业已从增量变为**缩量市场**。
-   **产能悖论**：白酒越老越值钱，新产能短期出不了好酒；且在过剩行业新建酒厂无异于自杀。

**结果**：每年几百亿的利润，没有地方按30%的ROE再投出去。

### 3. 要素三：再投资回报率不低于原ROE？
**不满足**。钱无处可去，只能面临两难：

-   **路径A：分红**
    茅台ROE 30%，PB约6倍（数据截至2026年年中）。若全额分红，股东实际回报率 = $30\% \div 6 = 5\%$。高PB像除数一样，将高ROE稀释为平庸回报。而且这已经是乐观上限——茅台实际分红率约50%-75%（含特别分红），当前实际股息率只有2%-3%。
-   **路径B：留存买理财**
    理财收益仅2%-3%。随着净资产膨胀，低收益资产占比增加，综合ROE被持续拉低（如同学霸加考了几门60分的科目，平均分下降）。

> **白酒的两难困境**：分红被PB打折，不分红被理财稀释。怎么走都不对。

### 等等，有没有第三条路——提价？

白酒和普通高ROE公司最大的不同，是**提价几乎不占用资本**：出厂价涨10%，不需要扩产能、不需要大额资本开支，利润直接增厚。这本质上是“无资本投入的高ROE再投资”，也是白酒过去十年利润增长的最大来源——销量基本没涨，增长全靠提价和产品结构升级。

那为什么这条“无本万利”的路救不了现在的白酒？

-   **批价倒挂**：出厂价能提的前提，是终端批价与出厂价之间留得出空间。近两年茅台散飞批价已从高位大幅回落，缓冲被吃掉，提价窗口被关死。
-   **消费疲软**：商务宴请、礼赠需求收缩，即便提价也缺承接，反而会进一步压垮批价。

所以不是白酒没有第三条路，而是**在当下的量价双缩里，这第三条路也被堵死了**——它才只能退回“分红被PB打折、理财被稀释”的两难。

> **跟踪指标**：判断白酒景气度，盯住茅台散飞批价这个先行指标即可——批价企稳回升，才是提价逻辑重新成立的那一天。

## 四、 核心结论：好生意 ≠ 好投资

将白酒代入芒格框架检验：

| 要素 | 白酒现状 | 判定 |
| :--- | :--- | :--- |
| 高ROE | 30%+ | 满足 |
| 再投资能力 | 海外<3%，国内负增长 | 不满足 |
| 再投资回报率 | 无机会，仅2-3%理财 | 不满足 |

**最终推演**：
白酒ROE虽是30%，但在6倍PB下，长期实际回报约为 **5%**。
-   5%仅略高于银行存款，却需承担股市波动、政策变化（如白酒消费税改革）、消费变迁等多重风险。
-   **风险收益比极不划算。**

### 观点总结

1.  **年轻人不喝白酒不是问题**，头部企业的生意依然是好生意。
2.  **真正的问题是：好生意太贵了，且增长路径被堵死。**
3.  **高PB + 不能扩产 = 回报稀释**。好生意配高PB，对普通投资者而言只是纸面富贵。
4.  **适用性**：此逻辑适用于所有“高ROE + 高PB + 无再投资空间”的公司。看到高ROE先问三个问题：钱能再投吗？回报有原来高吗？PB几倍？

> **如果茅台PB跌到2倍以下，那是另一个故事；同框架下，PB砸到2倍以下的中小白酒也值得单独看。但在当前6倍PB下，我不看好高PB白酒。**
