打工的最终目的是为了不打工，打工本质上是没有出路的。因此我决定系统地学习投资。投资固然有风险，但量化交易已经证明：通过严谨的模型与公式，买卖时机的选择是可以被计算和优化的。既然如此，我认为一个人只要积累足够的知识、掌握充分的信息，同样有能力识别风险、把握机会。这个网站将作为我的学习日志与知识库，记录我在投资路上的每一步探索与思考。

本质上大众对于 A 股的评论过于妖魔化。我觉得原因是中国人闷声发大财的传统：大家美美赚到钱了一般是不会发声的，只有亏钱的时候叫得比谁都大声。所以我们在牛市的时候很少会听到什么声浪，那反而在熊市的时候我们总是能听到大家抨击 A 股的一些声音。但其实我觉得 A 股是普通人能乘上时代红利发展的门槛最低、最直接的一个路径了，毕竟老板给你画的饼可能永远都不会实现，但 A 股如果涨停，你的财富第二天就是得到 10% 的增长。可以在同花顺或者东方财富打开任意一只股票的日K线图，肯定会有一段时间的增长，或者一个月、一星期。在这段时间如果买入，那么这些股民的财富是实打实增长了这么多。直接把 A 股归为是赌场、割韭菜的地方，我觉得过于因噎废食。

🏫 国内升学体系
| 学历阶段 | 对应投资标的 | 核心特征与风险描述 |
| :--- | :--- | :--- |
| 小学（推测） | [国债 / 债券型基金](content/01债券基金.md) | 开始有一些难度，但是确实不难，只要学没有不会的。 |
| 初中 | [中证红利 / 低波基金](content/02中证红利低波基金.md) | 学习内容开始有难度，偶尔会遇到难题。学生间的成绩真正有了区分度，但整体可控。学校好、班主任负责、跟着教学计划走就行。 |
| 高中 | 沪深300 / 指数基金 | 大量出现难题，内容有深度。需真下功夫，成绩高低明显，对个人水平有要求。有人不上了。 |
| 大学本科 | 大A各类板块ETF | 可选感兴趣的专业大类，但题目体现“专业”，对天赋/运气有要求，很多人会挂科。 |
| 研究生 | 大A个股 | 单独研究课题，更像探索实验，对综合素质/运势要求高。热门易出成果，冷门难研究但成功收获大。延毕、劝退常见，开始有人跳楼。 |
| 博士 | 科创、期货、两融等 | 进入专业领域，无明确“老师”“课本”，无标准答案，靠自己悟。开始批量跳楼。 |
