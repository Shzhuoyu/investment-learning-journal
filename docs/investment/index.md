打工的最终目的是为了不打工，一直打工就相当于一直卖身。投资固然有风险，但量化交易已经证明：通过严谨的数学模型与公式，买卖时机的选择是可以被计算和优化的。既然如此，我认为一个人只要积累足够的知识、掌握充分的信息，同样有能力识别风险、把握机会。这个网站将作为我的学习日志与知识库，记录我在投资路上的每一步探索与思考。

大众对于 A 股过于妖魔化。我觉得原因是“亏钱声大、赚钱沉默”的幸存者偏差。 A 股是普通人能乘上时代红利发展的门槛最低、最直接的一个可靠路径了，老板给你画的饼可能永远都不会实现，但买的股票如果涨停，你的财富第二天就是得到 10% 的增长。可以在同花顺或者东方财富打开任意一只股票的日K线图，肯定会有一段时间的增长，或者一个月、一星期。在这段时间如果买入，那么这些股民的财富是实打实增长了这么多。直接把 A 股归为是赌场、割韭菜的地方，我觉得过于因噎废食。

| 初中 | [中证红利 / 低波基金](content/01-基础/债基·红利低波·沪深300.md#dividend-lowvol) | 学习内容开始有难度，偶尔会遇到难题。学生间的成绩真正有了区分度，但整体可控。学校好、班主任负责、跟着教学计划走就行。 |
| 高中 | [沪深300 / 指数基金](content/01-基础/债基·红利低波·沪深300.md#csi300) | 大量出现难题，内容有深度。需真下功夫，成绩高低明显，对个人水平有要求。有人不上了。 |
| 大学本科 | 大A各类板块ETF | 可选感兴趣的专业大类，但题目体现“专业”，对天赋/运气有要求，很多人会挂科。 |
| 研究生 | 大A个股 | 单独研究课题，更像探索实验，对综合素质/运势要求高。热门易出成果，冷门难研究但成功收获大。延毕、劝退常见，开始有人跳楼。 |
| 博士 | 科创、期货、两融等 | 进入专业领域，无明确“老师”“课本”，无标准答案，靠自己悟。开始批量跳楼。 |
