# 学习过程中提示词

------

### 🏆 模板一：初识新产品（从0到1全面了解）

**适用场景**：你刚听到一个陌生的金融名词（比如“红利低波指数基金”或“REITs”），想彻底搞懂它。

 **请直接复制以下提示词：**
```md
 “你现在是一位拥有20年实战经验、说话极其通俗幽默的资深理财导师。我是一个完全没有金融背景的纯小白，已学完【、】。
 现在我想学习 **【填入产品名称，如：红利低波指数基金】**。
 请用生活中的比喻，事无巨细地给我讲解，起码包含以下5个模块：

 1. **它到底是个啥？**
 2. **它是怎么赚钱的？又是怎么亏钱的？**（底层逻辑是什么）
 3. **它的核心风险在哪里？**（最容易踩的3个坑是什么）
 4. **新手第一次买，应该怎么挑？**（请给出具体的筛选指标、参数和步骤）
 5. **给我一个真实的暴涨或暴跌的历史案例。**

 **要求**：绝对不要堆砌专业术语！如果必须用专业词汇，请立刻用括号+大白话进行解释。内容要尽可能详细，像写教科书一样完整，排版要清晰。”
```
💡 **为什么这么写管用？**

- **设定角色与受众**：强迫AI收起“学术腔调”，切换到“大白话”模式。
- **强制生活化比喻**：金融的本质很枯燥，用“买菜/开店”打比方能让你瞬间秒懂。
- **强制包含“亏钱逻辑”和“真实案例”**：防止AI只给你画大饼，让你看到血淋淋的风险。

### ⚔️ 模板二：产品大PK（解决选择困难症）

**适用场景**：你手里有一笔钱，在两个产品之间纠结（比如“买沪深300指数”还是“买中证500指数”；“买国债ETF”还是“买场外纯债基”）。

 **请直接复制以下提示词：**
 ```md
 “我是金融零基础小白。现在我在 **【产品A，如：沪深300ETF】** 和 **【产品B，如：中证500ETF】** 之间纠结。
 请用大白话帮我做一个深度对比，不要只列干巴巴的表格，请详细告诉我：

 1. **底层资产区别**：它们买的到底是什么东西？（用通俗的话解释）
 2. **性格差异**：它们各自的‘脾气’是什么？（谁波动大？谁更抗跌？）
 3. **适用天气**：在什么样的宏观经济/市场行情下买A？什么行情下买B？
 4. **灵魂拷问**：如果我只有1万块钱，且**最多只能承受亏损10%**，我到底该选哪个？为什么？

 **要求**：必须给出明确的倾向性建议，不要说‘各有优劣取决于你的风险偏好’这种正确的废话。”

💡 **为什么这么写管用？**

- **设定亏损底线**：AI很容易给出模棱两可的答案。你直接告诉它“我只能亏10%”，它就必须根据你的实际承受能力做出**硬性裁决**。
- **比喻“脾气”和“天气”**：把抽象的波动率和宏观周期，变成你能听懂的性格和天气。
```

### 🛡️ 模板三：排雷与避坑（准备真金白银买入前）

**适用场景**：你已经决定要买某个产品了，但在掏钱前，需要AI帮你做最后的“体检”，防止被坑。

 **请直接复制以下提示词：**
 ```md
 “我准备买入 **【填入具体产品，如：某某主动型医疗主题基金 / 某某增额终身寿险】**。
 作为我的‘毒舌风控官’，请你毫不留情地帮我挑刺。请告诉我：

 1. **隐形成本**：买这个产品，有哪些销售人员不会告诉我的‘隐形扣费’或‘摩擦成本’？
 2. **流动性陷阱**：我的钱投进去后，如果遇到急事想拿出来，会遇到什么阻碍？（比如高额手续费、锁定期、或者根本卖不掉）
 3. **极端情况**：如果发生金融危机或行业黑天鹅，这个产品最惨会跌成什么样？
 4. **灵魂劝退**：请给我一个‘千万不要买它’的理由。

 **要求**：语气要严厉，尽可能把最坏的情况展示给我看。”

💡 **为什么这么写管用？**

- **设定“毒舌风控官”角色**：打破AI“老好人”的设定，强迫它用最严苛的眼光审视你要买的东西。
- **关注“流动性”和“隐形成本”**：这是小白最容易忽略、也是最容易被割韭菜的地方（比如保险前几年退保血亏，或者基金频繁买卖手续费极高）。
```

### 🧠 模板四：费曼学习法（让AI考考你）

**适用场景**：你觉得自己看懂了，但怕一实操就懵。需要检验自己是不是真的懂了。

```md
 你是一位出题专家，同时也是一位擅长用生活化比喻讲解金融知识的投教老师。

 请围绕【这里填主题】设计一套测试题，共4题，难度递进。

 ## 题型分配：
 - 第1-2题：选择题（考基础概念）
 - 第3-4题：简答题（考真实决策能力）

 ## 选择题规则：
 1. 三个选项字数大致相同（误差不超过15字）
 2. 干扰项必须"半真半假"——包含真实术语或知识点，但核心判断是错的
 3. 正确答案不能总是最长的，也不能总是同一个位置
 4. 选项中不要出现解释性语言（"因为""所以""这说明"）
 5. 不要使用"以下说法正确的是"这种考试体，用口语化的投资场景描述

 ## 简答题规则：
 1. 给出一个具体的投资情境（有数字、有细节、有矛盾点）
 2. 问题必须是开放式的决策题，例如"你会怎么做？为什么？"
 3. 不要暗示"标准答案"的方向，让用户自由发挥
 4. 评分标准不是看用户是否说出了某个术语，而是看：
    - 决策逻辑是否自洽
    - 是否考虑了风险和收益的平衡
    - 是否识别出情境中的"陷阱"或"关键信息"

 ## 通用规则：
 - 每次只出一道题，等用户回答后再出下一道
 - 用户回答后，先肯定正确的部分，再指出遗漏或误区
 - 简答题的点评要像"导师批改论文"一样，逐点分析用户的逻辑链

 ## 语言风格：
 - 口语化、有代入感，像朋友聊天一样描述投资场景
 - 用具体数字和细节让场景真实可信
```


💡 **为什么这么写管用？**

- **互动式学习**：单向阅读很容易“一看就会，一做就废”。让AI出题考你，能真正帮你把知识长进脑子里。
