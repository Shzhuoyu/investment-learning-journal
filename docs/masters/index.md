# 🧠 大佬思想学习

> 学习大师的思维框架，站在巨人的肩膀上看投资。

## 为什么学习投资大师？

投资大师们经历了数轮牛熊周期，他们的思想经过了时间的检验。学习他们，不是为了简单复制，而是为了**建立自己的投资哲学**。

## 大师专栏

### 🟢 沃伦·巴菲特
> "在别人恐惧时贪婪，在别人贪婪时恐惧。"

核心思想：价值投资、护城河、能力圈

### 🔵 查理·芒格
> "我没有什么要补充的。"

核心思想：多元思维模型、逆向思维、人类误判心理学

### 🟡 彼得·林奇
> "投资你最了解的东西。"

核心思想：成长投资、十倍股、日常生活中的投资机会

### 🔴 瑞·达利欧
> "痛苦 + 反思 = 进步。"

核心思想：经济机器模型、风险平价、原则驱动

---

::: tip 📖 学习建议
每位大师都有其独特的背景和风格，建议：
1. 先通读各大师的核心思想
2. 找到与自己性格和理念最契合的一位深入学习
3. 融合多位大师的思想，形成自己的体系
:::
