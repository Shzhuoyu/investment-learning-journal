# DeepVan 知乎著名答主

#### 在2026年7月提出了自己对下半年的看法:
-   底层核心投资框架
    -   定价底层公式：股价 = EPS净利润 × 估值
        -   长期上涨核心：企业持续利润增长
        -   各时代标杆：茅台、宁德、中际旭创
    -   企业三阶段投资模型
        -   概念期（人形机器人/商业航天）
            -   特征：无业绩、情绪驱动，涨跌剧烈
            -   操作：提前潜伏，不高位追涨
        -   业绩成长期（AI算力、创新药）
            -   特征：机构抱团，超额收益稳定
            -   操作：中长期持有，跟踪业绩兑现
        -   成熟期（高股息公用/银行）
            -   特征：外资、保险偏好，震荡防御
    -   周期关键规律
        -   股价高点提前业绩高点 3–6 个月
        -   投资赚预期差，不滞后财报
    -   机构抱团逻辑
        -   历史阀值：茅指数 49%，当前 AI 拥挤度 52%
        -   抱团瓦解后资金持续切换新高景气赛道
-   三层宏观周期嵌套体系
    -   长周期：康波周期（原 50 年，现缩至 40 年）
        -   当前位置：第五轮信息周期末，第六轮 AI 周期初
        -   切换特征：大宗商品涨价（贵金属 → 工业金属 → 原油 → 农产品）
    -   中周期：朱格拉 9–10 年设备周期
        -   A 股牛市节点：05、15、25 年贴合设备更新
    -   短周期：基钦 3.3 年库存周期
        -   A 股小牛熊轮换核心驱动
        -   24 年前走完一轮三年熊市
-   宏观跟踪核心观测指标
    -   经济增长维度：M1/M2、10 年期国债收益率、PMI、工业增加值
    -   通胀盈利维度：CPI、PPI（直接影响企业利润率）
    -   核心变量：流动性宽松直接抬升市场整体估值
-   全球地缘与国内宏观大背景
    -   中美三大霸权循环逻辑
        -   美国闭环：军事 → 科技 → 美元金融霸权
        -   国内突破方向：军工装备、国产大模型、人民币国际化
        -   金融强国体现：关税战国家队快速托底市场
    -   中东地缘冲突影响
        -   核心变量：霍尔木兹海峡原油供给
        -   传导链条：油价上涨 → 全球通胀抬升 → 压制风险资产
        -   国内对冲：战略石油储备 + 新能源产业布局
    -   国内长期三大发展主线
        -   高质量增长
        -   硬核科技自主可控
        -   持续加码提振内需（当前外需单一依赖）
-   2026 下半年市场整体判断
    -   中长期大势
        -   月线旗形形态，突破后回踩支撑
        -   市场大趋势：慢牛长牛，国家队托底，3700 点为政策底
        -   短期走势：波动大幅放大，存在二次探底机会
    -   海外外部核心风险
        -   美元周期拐点：24Q3 启动贬值周期，26 下半年临近尾声
        -   美联储新主席风格偏鹰，加息预期反复扰动成长股
        -   潜在风险：日元套息交易集中平仓冲击市场
        -   时间窗口：美国中期大选前政策观望
    -   AI 产业链深度解读
        -   行业级别：大于新能源，第六轮康波核心主线
        -   当前压力点：云厂商资本开支高、现金流承压；存储涨价引发地缘博弈
        -   关键观测：OpenAI Codex 等 C 端新应用落地
        -   资金切换方向：从海外硬件转向国产算力、中下游应用
-   下半年核心配置赛道（杠铃均衡策略）
    -   进攻主线 1：国产算力 / 科创芯片
        -   支撑逻辑：国产替代加速、科创板业绩领先
        -   催化：长江存储、宇树等硬核企业陆续 IPO，政策维稳
    -   攻守主线 2：创新药（优先港股标的）
        -   催化：海内外审批政策放松、药企管线并购需求
        -   优势：上半年被科技板块持续吸金，超跌修复空间大
    -   防御主线 3：高股息资产
        -   特征：与科技成长跷跷板行情
        -   作用：平滑账户波动，大资金均衡配置必备
    -   其他细分机会
        -   储能：AI 算力电力需求 + 全球能源安全
        -   工业金属资源：大宗周期回暖预期
        -   题材概念：具身智能、商业航天（仅短线潜伏）
-   实操交易方法论
    -   高位被套解套方案
        -   纯涨价上游（存储、铜箔、PCB 原材料）：反弹减仓，难创新高
        -   硬核业绩算力龙头：长期持有，忽略短期震荡
    -   长 / 中 / 短线差异化操作
        -   长线（5 年+）：看月线大周期，押注产业长期趋势
        -   中线（1 年维度）：重点跟踪行业景气度，配置赛道 ETF / 龙头
        -   短线：博弈情绪、技术、事件，普通投资者不适合，量化占优
    -   散户亏损核心根源
        -   羊群效应、追涨杀跌，市场仅 10% 人持续盈利
        -   优化建议：逆向思维，学习行为金融学
-   问答环节补充观点
    -   AI 泡沫 vs 2000 互联网泡沫
        -   相同：前期算力大规模资本投入
        -   差异：当年无落地商用；当前看 AI 应用成本下行、C 端普及
        -   市场杂音：自媒体渲染危机多为流量变现
    -   医药板块周期逻辑
        -   上半年：科技持续吸金，医药长期震荡躺平
        -   下半年机会：科技波动分流资金，创新药做震荡防守仓
    -   仓位配置思路
        -   杠铃策略：成长赛道 + 防御板块均衡搭配
        -   预留现金，等待二次探底低吸机会
