# 桂墨一直都在

## 观点：目前有什么股票，可以长期持有10年？
美的集团，家电龙头之一，家电智能机器人未来前景巨大，兼具成长性的红利股，80元以下放心持有。

金风科技，全球风电整体解决方案提供商，无退市风险，可大胆持有，16元以下闭眼入。

杰瑞股份，全球最大的增产完井设备提供商，盈利强劲，分红不错，成长性强，位置略有点高，60以下闭眼入。

特变电工，变压器行业首家上市公司，重大装备制造业核心骨干企业，电力发展必不可少，依旧看好，20元以下可放心持有。

山东黄金，中国最大的国有控股黄金矿业上市公司之一，黄金储量巨大，30以下可放心持有。

紫金矿业，全国最大的黄金生产企业，市值低估，盈利强劲，同时还拥有铜矿等有色金属，前景很好，30元左右放心进场。

中天科技、亨通光电，量子科技的电缆提供商，同时又是社保等基金持有股份，稳中有进前景不会差，16元和20元以下耐心持有。

达仁堂、甘李药业，心血管疾病、糖尿病药物生产企业，未来老龄化日益加重，老年慢性病药物需求量前景无限，不过达仁堂位置有点高了，最佳位置是30元以下，甘李药业65元位置可以入手。

想吃股息，拿一些高息股：中国神华、中国海油、中谷物流、中远海控、长江电力、东阿阿胶。
